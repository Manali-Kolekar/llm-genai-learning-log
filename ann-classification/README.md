# ANN for Classification — Multi-Class Prediction using PyTorch

Implemented an **Artificial Neural Network (ANN)** in **PyTorch** for a multi-class classification problem. The model learns to classify input samples into one of **7 output classes** using fully connected (dense) layers and the ReLU activation function.

### Model Architecture

* **Input Layer:** Number of neurons equal to the number of input features.
* **Hidden Layers:** Two fully connected layers with **64 neurons** each, followed by **ReLU** activation.
* **Output Layer:** 7 neurons, one for each class. No activation function is applied since `CrossEntropyLoss` internally applies **Softmax**.

### Key Learnings

* Learned why **feature scaling** is important before training an ANN. Scaling input features prevents large-valued features from dominating the learning process and helps gradient descent converge faster.
* Understood the importance of converting labels to **`torch.long`**, as `CrossEntropyLoss` expects integer class indices rather than one-hot encoded vectors.
* Learned how to prepare datasets using **TensorDataset** and **DataLoader**, enabling efficient mini-batch training and data shuffling.
* Gained practical experience with the complete deep learning workflow in PyTorch:

  * Converting NumPy arrays into tensors.
  * Creating custom neural network models by inheriting from `nn.Module`.
  * Defining the forward pass using `nn.Sequential`.
  * Training the network using forward propagation, backpropagation, and the **Adam** optimiser.
  * Switching between `model.train()` and `model.eval()` modes during training and evaluation.
  * Disabling gradient computation with `torch.no_grad()` during testing to reduce memory usage and improve inference speed.
* Learned how model predictions are generated by selecting the class with the highest output score (`torch.max`) and how classification accuracy is calculated by comparing predicted labels with the true labels.
