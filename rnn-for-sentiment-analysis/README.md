# RNN for Sentiment Analysis — IMDB Movie Reviews

Built a **Recurrent Neural Network (RNN)** in **PyTorch** to classify movie reviews from the **IMDB Movie Reviews Dataset** as either **positive** or **negative**. The project covers the complete Natural Language Processing (NLP) pipeline, from text preprocessing to model training and evaluation.

### Dataset

* IMDB Movie Reviews Dataset
* Binary Sentiment Classification (Positive / Negative)

### Text Preprocessing

Implemented a complete preprocessing pipeline to improve the quality of textual data before training:

* Converted all text to lowercase for consistency.
* Removed URLs and HTML tags to eliminate irrelevant information.
* Removed punctuation and special characters.
* Removed English stopwords using NLTK.
* Applied Porter Stemming to reduce words to their root forms.
* Encoded sentiment labels using `LabelEncoder`.
* Converted text into numerical feature vectors using **TF-IDF Vectorization** (maximum 5000 features). 

### Model Architecture

* **Input Layer:** TF-IDF feature vectors (5000 features).
* **RNN Layer:** Single-layer Recurrent Neural Network with **128 hidden units**.
* **Output Layer:** Fully connected layer with one neuron for binary classification.
* **Activation:** Sigmoid applied during training for probability prediction.
* **Loss Function:** Binary Cross Entropy Loss (`BCELoss`).
* **Optimizer:** Adam Optimizer.

### Key Learnings

* Learned how raw text must be cleaned before being used by machine learning models.
* Understood the purpose of each preprocessing step and how it improves model performance.
* Learned how **TF-IDF** converts textual data into numerical vectors by assigning higher importance to informative words while reducing the influence of frequently occurring words.
* Understood why sparse matrices generated by TF-IDF must be converted into dense tensors before training in PyTorch.
* Learned how an RNN processes sequential information by maintaining a hidden state that captures context from previous inputs.
* Gained hands-on experience building custom neural networks by inheriting from `nn.Module` and implementing the forward pass.
* Learned the complete PyTorch training workflow, including mini-batch loading with `DataLoader`, forward propagation, backpropagation, parameter optimisation, and evaluation using `model.eval()` and `torch.no_grad()`.
* Understood how sigmoid outputs are converted into binary predictions and how classification accuracy is calculated.
